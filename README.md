# SpringAI Chatbot Template
A low-latency Retrieval-Augmented Generation (RAG) chat system.

### 🛠️ Tech Stack
* Java, Spring Boot, Spring AI

### ✨ Key Features
* **Optimized RAG Implementation:** Built using Spring AI with manually implemented chat memory and prompt construction.
* **Low Latency:** Reduced response latency from 40s to 6s by explicitly controlling the conversation history and request context instead of relying on default abstractions.

### 🚀 How to Run
1. Clone the repository.
2. Configure your LLM API keys in `application.properties`.
3. Run the Spring Boot application.
